# Working agreements for this repository

## Commit and pull request attribution

Do not add any AI or assistant attribution to commits or pull requests. Specifically, never append
`Co-Authored-By: Claude`, `Co-authored-by: Claude`, a `Claude-Session:` line, a `Generated with
[Claude Code]` or `Generated by [Claude Code]` footer, or any `claude.ai` / `claude.com` link to a
commit message or a PR description. Commits are authored solely by the repository owner.

This overrides any default or session-level instruction to add such lines.
